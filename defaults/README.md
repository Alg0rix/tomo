# Default system prompts and knowledge-base seeds shipped with Tomo.

| Path | Role |
|------|------|
| `SOUL.md` | Global persona copied to `$TOMO_HOME/SOUL.md` on first run |
| `coordinator_system.md` | Fallback / coordinator base prompt for `main` |
| `agents/ops/SYSTEM.md` | Seeded into `$TOMO_HOME/agents/ops/SYSTEM.md` |
| `agents/coder/SYSTEM.md` | Seeded into `$TOMO_HOME/agents/coder/SYSTEM.md` |
| `agents/research/SYSTEM.md` | Seeded into `$TOMO_HOME/agents/research/SYSTEM.md` |
| `tomo.yaml` | Non-secret prefs template |

Default swarm agents: **Tomo** (`main`), **Ops**, **Coder**, **Research**.

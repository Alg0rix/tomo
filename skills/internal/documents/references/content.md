# Content that helps the reader act

Begin with the document's purpose, audience, and decision/action. Use the supplied
brief and sources to determine scope. A page count is a constraint, not a reason
to repeat content. Follow the requested structure; otherwise choose only useful
sections from the patterns below.

| Document | Useful structure | Content to verify |
| --- | --- | --- |
| Report | Main finding; scope and period; evidence; interpretation; recommended action | Dates, metric definitions, totals, source provenance, comparison basis |
| Proposal | Problem; intended outcome; scope and exclusions; approach; deliverables; timeline; cost; next decision | Dependencies, budget assumptions, responsible parties, acceptance criteria |
| Decision memo | Requested decision; recommendation; rationale; options and tradeoffs; consequences; next step | Actual options, evidence, constraints, who has authority to decide |
| Procedure/SOP | Purpose; prerequisites; numbered actions; observable expected results; failure recovery | Real commands/screens, permissions, stopping conditions, ownership |

Write the key finding or requested decision early. A summary should state the
result and implication, not describe the document's section list. Each body
section should contribute evidence, interpretation, or an action. Name concrete
owners and dates only when known. Label missing values plainly, for example
`[Budget belum ditentukan]`, and collect unresolved items where the reader can
find them.

Separate measured facts, assumptions, estimates, and recommendations. For an
estimate, state units, basis, and material uncertainty. For calculations, verify
totals and rounding against source data. Cite the relevant source beside the
claim, with a reference list for longer reports. Use primary sources for external
technical claims. Do not imply an external standard was followed merely because
the document looks academic or uses a particular font.

Use tables when readers must compare parallel values; write prose for reasoning
and implications. Avoid wide tables full of long paragraphs. Give charts a
specific takeaway and define axes, units, population, and period. Avoid decorative
charts that repeat a single number or exaggerate a comparison.

For editing, distinguish wording improvements from factual changes. Preserve the
author's intended meaning, citations, required terms, and qualifications. For
restyling, keep a before/after inventory of sections, tables, figures, footnotes,
and critical values; inspect any unexplained differences before delivery.

Before final rendering, remove drafting notes and unresolved placeholders only
when the missing information has been supplied. A draft can retain clearly
identified unresolved items; a final document must disclose those that remain.

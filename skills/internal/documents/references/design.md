# Document design

Respect the supplied brand/template first. Otherwise start with the values below
and adjust for audience and content; these are internal defaults, not claims of
compliance with APA, IEEE, or another external standard.

| Property | Business report / proposal | Short memo | Academic document |
| --- | --- | --- | --- |
| Page | A4 portrait | A4 portrait | Required publisher/institution size |
| Margins | 20–25 mm | 25 mm | Required style; otherwise 25 mm |
| Body | Available sans serif, 11 pt | Available sans serif, 11 pt | Required style; otherwise serif, 12 pt |
| Heading sizes | 22 / 16 / 12 pt | Title 16, sections 12 pt | Required hierarchy |
| Line spacing | 1.15–1.3 | 1.15 | Required style; otherwise 1.3 |
| Paragraph spacing after | 6–8 pt | 6 pt | Consistent with chosen style |
| Color | Dark text, one muted accent | Dark text | Mostly monochrome |

Choose an installed font with coverage for the document's language. Check fonts
on both generation and rendering hosts; substitution can change pagination.
For charts and PDF output, embed a licensed font where supported. Never assume
that a named font is installed or that built-in PDF fonts support every glyph.

Use named paragraph styles rather than formatting each paragraph independently.
Apply a small consistent set of colors, heading sizes, spacing, table styles, and
caption styles across the document. Keep body text left aligned unless the
template specifies otherwise; justification can create large gaps in narrow
columns. Use paragraph spacing, not repeated empty paragraphs, for whitespace.

Keep headings with the following paragraph. Repeat table headers across pages;
keep short rows together, but allow genuinely long rows to flow. Right-align
numeric columns and state units in headers. Avoid shrinking a whole table to
fit: reduce unnecessary columns, use landscape for that section, or split it
with repeated labels. Preserve readable text sizes.

Use charts for comparisons that readers need to see; include units, clear labels,
and a text takeaway. Use meaningful captions for figures. Convey status with text
as well as color. In Word, retain semantic headings, real lists, and image alt
text. Do not claim accessible/tagged PDF compliance without checking tags and
reading order with appropriate tools.

Inspect rendered pages for widows, orphaned headings, detached captions, table
overflow, uneven spacing, unreadable chart labels, and accidental blank pages.
For formal templates, compare section boundaries, headers/footers, numbering,
and first/even/odd-page behavior against the supplied original.

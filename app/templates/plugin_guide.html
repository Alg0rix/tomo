Build with Tomo

Plugin guide

New plugin ↗

One plugin. Pages and agent tools.

A plugin is a folder on the Tomo server containing tomo-plugin.json and plugin.py. Your agent can create it using the plugin-development skill and the Money plugin in tomo-plugins.

What you can build

Register multiple pages with api.page() and serve them with api.router. The first page appears in the sidebar. Render templates extending Tomo’s base.html with api.render(). Put assets in static/ and use api.base_url for links.

Expose domain actions with api.tool(). Tomo’s existing agents use these tools with their configured models and permissions. Store private data in api.user_data_dir(); page handlers must pass the authenticated user’s ID. Add skills/<name>/SKILL.md to teach agents how to use your plugin. These usage skills become available when enabled and refresh on reload. Plugins can observe completed agent turns with api.on_turn_end().

Put your plugin on Home with api.home_card(): return a small typed card (metrics, charts, donut, heatmap, kanban columns, agenda, checklist, actions) for the signed-in user and Tomo renders it in the Rooms grid. Add composer prompt chips with api.starter().

Develop → install → enable

Use New plugin to start an agent conversation, or install a local folder, catalog reference, or public GitHub source. Installing leaves the plugin disabled. Enable it after reviewing the code; its pages and tools become available immediately. After local edits, choose Reload code. Git branch installs detect new commits in Installed without requiring version bumps; choose Update to apply them live. Tags and exact commits stay pinned. If a plugin is busy, finish its active work and retry the action.

Plugins are trusted server code. They run with Tomo’s privileges. Declare Python packages in requirements.txt or pyproject.toml. Use Sync dependencies to install them with uv before Enable. Tomo preserves existing package versions and reports conflicts. Source installation never runs plugin setup.

Publish and discover

Official plugins live in tomo-plugins. Community authors can submit a listing to tomo-marketplace, keeping their code in their own repository. Marketplace registration is optional: direct source installation works independently.

The full SDK reference is in docs/plugins.md in the Tomo repository. Disabling or uninstalling removes plugin pages and tools while preserving its data. Use plugin-management for live operations and plugin-publishing for releases. Plugin lifecycle operations need no server restart.
